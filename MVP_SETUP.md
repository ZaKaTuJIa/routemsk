## HTTPS — условие выпуска

16.09.2026 браузер получил ERR_CERT_COMMON_NAME_INVALID, curl — SEC_E_WRONG_PRINCIPAL.
HTTP отдаёт 200 без редиректа. Это наблюдение из среды аудита, а не глобальный мониторинг.
Проверить Settings → Pages: домен routemsk.ru, статус выпуска сертификата, источник main.
Проверить A/AAAA/CNAME у DNS-провайдера и отсутствие конфликтующих записей.
После выпуска валидного сертификата включить Enforce HTTPS по согласованию с владельцем.
Не обходить проверку TLS. До выпуска проверить HTTPS с независимого устройства/сети.
Canonical, sitemap и OG в PR используют целевой HTTPS-адрес; выпускать после восстановления HTTPS.

## СТС: фактическое поведение

Файл выбирается и проверяется локально (JPG/PNG/PDF, непустой, до 10 МиБ).
Ничего не отправляется на сервер, в Telegram API или WhatsApp.
Посетитель сам открывает мессенджер и прикрепляет документ.
Выбор файла на сайте необязателен. submitStsToServer — отклоняющая запрос заглушка.
Нельзя вызывать sts_upload_success после выбора файла или клика на мессенджер.

Будущая автоматическая доставка — отдельная задача, не реализована в v0.8:
серверная проверка формата/размера и безопасности файла, ограничения частоты,
утверждённые правила хранения/удаления и обработки данных, защищённые серверные секреты.
Ответ должен различать ошибку, принятие в очередь и подтверждённую доставку.
Только подтверждённая доставка допускает sts_upload_success.
Не хранить токены бота в HTML/JS и не логировать содержимое СТС.

## Юридические данные и доверие

В футере остаются честно обозначенные заглушки. Это незакрытая задача, не готовые документы.
Нужны фактический исполнитель, реквизиты, контакт для вопросов о данных,
утверждённые политика и согласие с учётом реального процесса передачи через мессенджеры.
Не выдумывать адрес, ИНН, отзывы, рейтинг или юридические гарантии.
Владельцу подтвердить цены, сроки и заявления об опыте с 2014 года / парке 100 авто.

## Проверка перед публикацией

- Валидный HTTPS; HTTP перенаправляет на HTTPS; домен и main в Pages подтверждены.
- Главная, robots.txt, sitemap.xml, favicon.svg, assets/og-cover.png отвечают 200.
- Неизвестный URL возвращает HTTP 404 с полезной страницей.
- Canonical и sitemap содержат только https://routemsk.ru/; 404 не включена.
- Telegram/WhatsApp/телефон ведут нужному получателю; не отправлять тестовые документы клиентам.
- 320/390/768/1280 px: нет переполнения страницы, кнопки доступны, этапы прокручиваются.
- FAQ работает с клавиатуры и без JavaScript; выбор файла корректно обрабатывает ошибки.
- После выпуска отправить sitemap в подтверждённые Яндекс Вебмастер / Search Console.
- Проверить реальный мобильный браузер, PageSpeed Insights и полевые Core Web Vitals.
